5. Cláusula vi — Documentação dos endpoints

Evidência no repositório: 30 route handlers Next em src/app/api/. Catálogo neste HTML. README.md aponta para esta secção. Não existe arquivo OpenAPI das rotas Next (o dump local public_openapi_schema.json é PostgREST, gitignored). AGENT.md (gitignored) descreve rotas que não existem nesta árvore (previsao/route.ts, stripe/checkout/route.ts, entre outras). Extraído do código em 3 de setembro de 2026.

Autenticação, em linguagem comum: anônimo — sem sessão; sessão — cookie de usuário Supabase via getUser(); admin — sessão + RPC is_admin (src/lib/auth/admin.ts); assinatura Stripe — header stripe-signature + STRIPE_WEBHOOK_SECRET; token interno — header x-internal-engine-token comparado a ENGINE_INTERNAL_TOKEN.

O middleware.ts protege páginas /dashboard, /calculadora, /calendario, /financeiro, /perfil e prefixo /admin. As rotas /api/* não são bloqueadas pelo middleware; cada handler aplica a própria regra.
